# Contributing

Thank you for your interest in contributing to SN Account Instance Hardening!

## How to Contribute

1. **Fork** the repository.
2. **Create a branch** for your feature or fix:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Make your changes** and commit them with clear, descriptive messages.
4. **Push** your branch and open a **Pull Request** against `main`.

## Guidelines

- Keep changes focused and scoped to a single issue or feature.
- Write clear commit messages.
- Test your changes before submitting a PR.
- Follow existing code style and conventions.

## Reporting Issues

If you find a bug or have a feature request, please [open an issue](https://github.com/SNCustomerSecurityTrust/SN-account-instance-hardening/issues).

## Code of Conduct

Please read and follow our [Code of Conduct](CODE_OF_CONDUCT.md).
