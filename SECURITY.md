# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Please do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please report them via email or by using GitHub's private vulnerability reporting feature on this repository.

## Scope

This policy applies to the code and configurations maintained in this repository.

## Response

We will acknowledge receipt of your report and provide an estimated timeline for a fix. We appreciate your help in keeping this project secure.
